Diseño funcional

Arquitectura del sistema

Flujo propuesto para operar el Gestor de Aprendizaje Experiencial.

DISEÑO DE REFERENCIA
1. Captura · Microsoft Forms
El profesor registra la experiencia y entrega la información solicitada.

2. Automatización · Power Automate
El flujo identifica el tipo de experiencia y crea el registro correspondiente en SharePoint.

3. Repositorio institucional · SharePoint
La lista GE_Historias conserva los datos y el estado de cada historia. Es la fuente oficial, no GitHub.

4. Gestión interna · Power Apps
La JAX consulta, revisa, solicita ajustes, valida y cambia estados. Acceso restringido al equipo autorizado.

5. Publicación · GitHub Pages
Solo recibe una versión depurada de las historias aprobadas y con autorización de publicación. No debe consultar SharePoint con credenciales desde el navegador.

Reglas de seguridad y publicación

• No publicar nombres, correos, datos personales ni evaluaciones internas sin autorización.
• No incluir contraseñas, tokens o secretos en archivos HTML o JavaScript públicos.
• La publicación debe usar un conjunto de datos separado, aprobado y anonimizado cuando corresponda.
• Mantener la trazabilidad y el control de cambios en SharePoint y Power Apps.
